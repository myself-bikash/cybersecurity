# Phase 3: Linux and Windows Fundamentals

## Phase objective

Become comfortable managing, configuring, troubleshooting, and securing Linux and Windows
operating systems. The source emphasizes both because servers, personal computers, enterprise
networks, and cloud infrastructure use them.

## Lessons

1. [Linux fundamentals](01-linux-fundamentals.md)
2. [Windows fundamentals](02-windows-fundamentals.md)
3. [Administration projects and review](03-administration-labs.md)

## Source reference fragments

The PDF contains webpage-title/domain fragments about Linux workstations and filesystems, Windows
uptime, Windows kernel topics, the Registry, Task Manager, and Event Viewer. They are incomplete
citations and are not presented as verified or recommended references.

## Progress checklist

- [ ] Explain the Linux architecture, distributions, filesystem, users, permissions, and services.
- [ ] Explain the Windows architecture, filesystem, NTFS permissions, and accounts.
- [ ] Locate the administrative tools and logs named in the course.
- [ ] Complete the Linux and Windows projects only on systems you own or are authorized to manage.
- [ ] Answer the Phase 3 review questions.

## Competency checkpoint

Explain how a local account, file permission, process, and service relate on one operating system.
Use a test system or a diagram, and record which logs or administrative views could help verify
your explanation.
