# Phase 12: Active Directory and Enterprise Security

## Phase objective

Understand how Windows enterprise environments manage identities, computers, authentication,
permissions, and security; investigate common identity risks; and practice administration and
defensive monitoring in an isolated lab.

## Progress checklist

- [ ] Explain Windows Server, AD DS, domains, trees, forests, objects, and domain controllers.
- [ ] Manage test users, groups, OUs, permissions, and Group Policy in an isolated domain.
- [ ] Explain LDAP, Kerberos, NTLM, DNS, authentication, and authorization.
- [ ] Describe trust relationships and apply least privilege and domain-controller hardening.
- [ ] Distinguish IAM from PAM and explain MFA, SSO, RBAC, and access lifecycle.
- [ ] Interpret selected Windows security events and explain SIEM correlation.
- [ ] Recognize AD attack concepts and their defensive controls without testing real environments.
- [ ] Build and document an isolated two-VM AD lab.
- [ ] Complete the final assessment and write a structured defensive investigation report.

## Safety and scope

All administration and monitoring exercises are restricted to test identities and systems that you
own or are explicitly authorized to use. Keep the lab on an internal or host-only virtual network;
do not bridge it to a home, school, or workplace network. Attack techniques are explained for
recognition and defense. This phase does not provide procedures for credential theft, password
cracking, unauthorized directory collection, or moving between real systems.

The PDF contains 17 modules and a 16-question assessment. The assessment page has no answer key;
the key in the final lesson is course-created and is not presented as source material.
