# Phase 9: Network and System Security

## Phase objective

Learn how to design and secure network infrastructure, harden endpoints and servers, manage
vulnerabilities and updates, protect recovery capability, and monitor infrastructure.

## Progress checklist

- [ ] Explain the 18 core topics and five advanced topics.
- [ ] Distinguish firewalls, IDS/IPS, NAC, VPN, and Zero Trust access.
- [ ] Apply system hardening, vulnerability-management, patch-management, and recovery concepts.
- [ ] Describe infrastructure monitoring, network intrusion detection, and network forensics.
- [ ] Complete the practical work using only owned systems or an isolated, explicitly authorized lab.

## Safe practice and source notes

Use your own Linux or Windows system, or isolated virtual machines. Do not scan or test networks
without authorization. Exercises in this phase focus on local configuration review, synthetic
events, provided vulnerability reports, and defensive analysis; they do not include exploit
procedures or instructions for testing third-party systems.
