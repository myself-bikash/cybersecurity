# Phase 7: Ethical Hacking and Penetration Testing

## Phase objective

Learn the professional process for authorized security assessment: scope and authorization,
reconnaissance, scanning concepts, vulnerability assessment, controlled validation, privilege
boundaries, reporting, remediation, and retesting.

## Progress checklist

- [ ] Distinguish passive and active reconnaissance and scanning.
- [ ] Understand CVE, CVSS, vulnerability prioritization, and validation.
- [ ] Explain exploit, proof-of-concept, payload, RCE, and privilege escalation conceptually.
- [ ] Create a professional report with evidence, remediation, and retesting.

## Safety and scope

Only assess systems you own or have explicit permission to assess. A publicly accessible system is
not automatically authorized. Keep vulnerable virtual machines isolated from public networks.

To avoid enabling unauthorized access, this course does not provide runnable reconnaissance,
scanning, exploitation, or privilege-escalation procedures. It retains the source's concepts and
uses fictional case studies, sanitized reports, and defensive lab exercises instead.

## Competency checkpoint

Write a sample rules-of-engagement outline for a fictional assessment: authorization, scope,
excluded systems, permitted methods, stop conditions, and reporting contacts. Review a sanitized
finding and propose remediation and retesting criteria without testing a real target.
