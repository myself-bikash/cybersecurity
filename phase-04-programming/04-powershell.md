# PowerShell

## Learning objectives

By the end of this lesson, you should be able to:

- Describe PowerShell's role in Windows administration and enterprise security.
- Identify the topics in the source's PowerShell syllabus.
- Explain the source example and cybersecurity applications.

## What is PowerShell?

PowerShell is Microsoft's command-line shell and scripting language. The source describes it as
useful for Windows administration and enterprise security.

## PowerShell syllabus

1. PowerShell fundamentals.
2. Variables and data types.
3. Operators.
4. Conditions.
5. Loops.
6. Functions.
7. Arrays and hashtables.
8. Pipeline.
9. Objects and properties.
10. File handling.
11. Error handling.
12. Processes and services.
13. Windows Registry interaction.
14. Active Directory administration basics.
15. Event-log analysis.
16. Automation and scripting.

The source's example is:

```powershell
Get-Process
```

It displays currently running processes.

## Cybersecurity applications

The source lists Windows system monitoring, user and permission management, event-log analysis,
security automation, and incident response.

## Practical lab: PowerShell task mapping

In an authorized Windows VM:

1. Use the source example to view running processes.
2. Explain which PowerShell syllabus topics are involved in reading output and handling errors.
3. Plan a report that summarizes a permitted event-log sample without including sensitive data.
4. Do not modify Registry settings, accounts, or Active Directory objects in a production
   environment.

## Key takeaways

- PowerShell supports Windows administration, automation, and security operations.
- Its syllabus includes variables, control flow, functions, collections, pipelines, objects,
  files, errors, system administration, event logs, and Active Directory basics.
- The source's simple example displays local processes.
