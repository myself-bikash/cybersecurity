# HTML and CSS

## Learning objectives

By the end of this lesson, you should be able to:

- Explain the purpose of HTML and CSS as web technologies.
- Identify the HTML and CSS topics listed in the source.
- Describe why the source connects forms and input fields with security.

## HTML and CSS

The source notes that HTML and CSS are not programming languages in the same sense as Python or
JavaScript, but are essential web technologies.

**HTML (HyperText Markup Language)** defines the structure and content of web pages. The source
lists:

- Elements and tags.
- Headings and paragraphs.
- Forms and input fields.
- Links and tables.
- Attributes.
- HTML document structure.

Understanding forms and input fields helps explain how websites collect user information and
handle input.

**CSS (Cascading Style Sheets)** controls the appearance and layout of web pages. The source lists:

- Selectors.
- Colors and fonts.
- Margins and padding.
- The box model.
- Flexbox and Grid.
- Responsive design.

The source says CSS has less direct importance in security testing than HTML and JavaScript, and
advises against spending excessive time mastering visual design.

## Practical lab: inspect a local page structure

Using a local page or an instructor-provided sample:

1. Identify headings, paragraphs, links, tables, forms, and input fields.
2. Describe which parts define structure/content and which affect appearance/layout.
3. Explain how a form collects user input without submitting it to an external service.

## Key takeaways

- HTML defines page structure and content.
- CSS controls appearance and layout.
- Forms and input fields are relevant to understanding how webpages collect information.
- The source prioritizes HTML and JavaScript over extensive CSS visual-design study for security.
