# Phase 4: Programming and Scripting

## Phase objective

Learn to write programs, automate security tasks, understand how software works internally, and
identify programming-related vulnerabilities. The source says learners need to read code, write
scripts, debug problems, and identify insecure implementations; expert software-development skills
are not a prerequisite for starting.

## Progress checklist

- [ ] Follow the source's recommended programming-language priorities.
- [ ] Complete the Python, Bash, and PowerShell fundamentals.
- [ ] Study SQL, JavaScript, and HTML/CSS for web security.
- [ ] Study C, Assembly, and Go at the source's recommended stages.
- [ ] Understand memory, networking, data structures, algorithms, and secure coding.
- [ ] Complete or document a plan for the six source projects.
- [ ] Answer the Phase 4 readiness questions before proceeding to Phase 5.

## Competency checkpoint

Write or annotate a small, harmless script that reads a controlled input, validates it, and
produces a clear result. Explain its assumptions and how you would test an ordinary and an invalid
input.
