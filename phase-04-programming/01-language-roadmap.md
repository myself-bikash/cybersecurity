# Programming Language Roadmap

## Learning objectives

By the end of this lesson, you should be able to:

- Explain why programming supports cybersecurity work.
- Identify each language or technology and its purpose and priority in the source.
- Follow the source's recommended learning order without trying to master every language at once.

## Why programming matters

Programming helps cybersecurity learners automate tasks, understand how software works, and
identify programming-related vulnerabilities. The source recommends learning enough to read code,
write scripts, debug problems, and identify insecure implementations; it does not require becoming
an expert software developer before starting ethical hacking.

## Language and technology priorities

| Language / technology | Main purpose in the source | Priority |
| --- | --- | --- |
| Python | Automation and security scripts | Essential |
| Bash | Linux automation | Essential |
| PowerShell | Windows automation | Essential |
| SQL | Database security | Essential |
| JavaScript | Web security | Important |
| HTML/CSS | Web fundamentals | Important |
| C | Memory and low-level security | Advanced |
| Assembly | Exploit development and reverse engineering | Advanced |
| Go | Security tooling | Optional |

## Recommended learning order

The source recommends beginning with Python, Bash, and PowerShell, followed by SQL, JavaScript,
and HTML. It recommends learning C and Assembly when studying low-level security and exploit
development; Go can wait until needed for security tooling.

The detailed priority order is:

1. Python: become comfortable writing programs independently.
2. Bash and PowerShell: automate Linux and Windows tasks.
3. SQL and JavaScript: prepare for web-application security.
4. HTML: understand webpages and forms.
5. C: understand memory, pointers, and low-level vulnerabilities.
6. Assembly: learn fundamentals for reverse engineering.
7. Go: learn later if needed for advanced security tools.

The source also lists HTML/CSS as important and Go as optional in its language table.

## Practical exercise

Choose one fictional cybersecurity task from the table and identify the language or technology
closest to it. Explain your choice using only the purposes listed in the source. Do not write or run
code against systems or data you are not authorized to use.

1. Select one task, such as summarizing a synthetic log or describing a webpage form.
2. Match it to a language or technology and cite its purpose from the table.
3. Name one prerequisite topic and one next step from the recommended order.

**Deliverable:** A three-row learning plan (task, technology with rationale, and next step) that
distinguishes essential, important, advanced, and optional skills.

## Key takeaways

- Programming supports automation, code understanding, and security analysis.
- Python, Bash, and PowerShell are the source's essential starting languages.
- SQL, JavaScript, and HTML/CSS support web and database security learning.
- C and Assembly are advanced; Go is optional.
