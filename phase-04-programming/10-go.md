# Go Programming

## Learning objectives

By the end of this lesson, you should be able to:

- Describe Go as introduced by the source.
- Identify all topics in the Go syllabus.
- Explain the source's optional-priority guidance and security-tool applications.

## What is Go?

Go (Golang) is a compiled programming language developed by Google. The source describes it as
simple, performant, and having built-in concurrency support.

## Go syllabus

1. Variables and data types.
2. Conditions and loops.
3. Functions.
4. Arrays and slices.
5. Maps.
6. Structures.
7. Interfaces.
8. Goroutines.
9. Channels.
10. Networking.
11. HTTP servers.
12. File handling.
13. Error handling.
14. Building command-line tools.

## Cybersecurity applications and priority

The source lists building network scanners, security utilities, command-line tools, and network
monitoring applications. Go is optional; the source advises not learning it before mastering
Python and essential scripting skills.

## Practical lab: syllabus planning

Create a study map that groups the Go topics into language basics, data structures, concurrency,
networking, files/errors, and command-line tools. Identify which topics would be relevant to one
source-listed application. Do not build or run a scanner against systems.

## Key takeaways

- Go is a compiled language and is optional in the source's learning plan.
- Its syllabus covers core programming, collections, concurrency, networking, HTTP servers, files,
  errors, and command-line tools.
- The source recommends learning Go only after Python and essential scripting.
