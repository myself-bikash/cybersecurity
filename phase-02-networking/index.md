# Phase 2: Networking Fundamentals

## Phase objective

Understand how computers communicate, how information travels across networks, how devices
identify one another, and how network communication can be attacked or protected. The source
emphasizes networking as a foundation for cybersecurity.

## Competency checkpoint

Trace a fictional browser request from a client to a service and back. Label addressing, name
resolution, transport, and application protocol at the level taught in this phase; identify where
your explanation depends on an assumption.
