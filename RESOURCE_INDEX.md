# Resource Index

## Purpose

This index highlights authoritative, maintained, and relevant public resources that support the cybersecurity curriculum. It is intended as a quality filter to avoid stale or low-value references.

## Foundational resources

### NIST

- Website: https://www.nist.gov/
- Why relevant: Core frameworks, guidance, and standards for security engineering and risk.
- Difficulty: Intermediate to advanced

### CISA

- Website: https://www.cisa.gov/
- Why relevant: Public guidance on cyber defense, threats, and operational resilience.
- Difficulty: Beginner to advanced

### OWASP

- Website: https://owasp.org/
- Why relevant: Priority guidance for web application and API security, plus threat modeling and secure coding practices.
- Difficulty: Beginner to advanced

### MITRE ATT&CK

- Website: https://attack.mitre.org/
- Why relevant: Adversary tactics, techniques, and procedures for detection and defense.
- Difficulty: Intermediate to advanced

### MITRE CWE

- Website: https://cwe.mitre.org/
- Why relevant: Common weakness taxonomy for secure design and software assurance.
- Difficulty: Intermediate to advanced

## Resource usage guidance

When selecting a reference, learners should check:

- Whether the source is official or maintained by a trusted organization
- Whether the content is suitable for their level of experience
- Whether it supports direct application to lab work or architecture review
- Whether the resource is current and relevant to the learning objective

## Quality principle

This resource index favors official documentation and trusted public guidance. It avoids outdated references unless a historical context is required.
