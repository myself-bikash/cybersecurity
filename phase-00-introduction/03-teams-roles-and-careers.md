# Security Teams, Roles, and Career Areas

## Learning objectives

By the end of this lesson, you should be able to:

- Explain the red-team, blue-team, and purple-team concepts in the source.
- Compare a security analyst role with a penetration tester role.
- Describe the cybersecurity specializations listed in the course.

## Red, blue, and purple teams

| Team / approach | Description in the source |
| --- | --- |
| Red team | Offensive security professionals hired to simulate attacks to test an organization's defenses. |
| Blue team | Defensive professionals who monitor environments, detect attacks, and respond to incidents. |
| Purple team | A collaborative methodology in which red and blue teams share insights to improve security. The source notes that it is not necessarily a separate group. |

## Security analyst and penetration tester

| Security analyst | Penetration tester |
| --- | --- |
| A defensive role focused on monitoring network traffic, analyzing alerts, and responding to active threats, often in a SOC. | An offensive security role that tests specified applications or networks during an agreed timeframe to identify security gaps. |

Both roles must follow their organization's authorization and scope requirements.

## Cybersecurity specializations

These specializations represent different cybersecurity career opportunities. The source lists
examples rather than prescribing a career path.

| Specialization | Main responsibility described in the source |
| --- | --- |
| Penetration testing | Find security weaknesses by exploiting systems during an authorized assessment. |
| Red teaming | Simulate realistic, full-scope attacker campaigns. |
| SOC analyst | Monitor network traffic and security alerts for threats. |
| Incident response | Handle, contain, and remediate active security breaches. |
| Cloud security | Protect cloud infrastructure, including AWS, Azure, and GCP, and its data. |
| Application security | Secure software code and development pipelines. |
| Digital forensics | Investigate digital evidence after a breach or for law enforcement. |
| Malware analysis | Reverse-engineer malicious software to understand its behavior. |
| Security engineering | Build and implement security controls and firewalls. |
| Governance, risk, and compliance (GRC) | Ensure adherence to security frameworks, laws, and policies. |

## Practical exercise: role matching

For each fictional task, select the closest specialization from the table and explain your choice:

1. Review alerts and monitor for suspicious activity.
2. Preserve and investigate digital evidence after an incident.
3. Help a team understand security gaps through an authorized assessment.
4. Build controls for an application development process.
5. Coordinate containment and recovery during a security incident.

Do not perform testing or access real systems as part of this exercise.

## Key takeaways

- Red teams simulate attacks within an authorized engagement; blue teams focus on defense.
- Purple teaming describes collaboration, not necessarily a separate team.
- SOC analysis and penetration testing have different primary responsibilities.
- Cybersecurity includes technical, investigative, operational, and governance specializations.
