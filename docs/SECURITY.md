# Security Policy

## Scope

This repository contains educational content, curriculum pages, and documentation for cybersecurity learning. The project is not intended to provide live exploit tooling or privileged access to real systems.

## Supported versions

This is a documentation-focused project. The project does not currently maintain a formal versioned security release model beyond repository content updates.

## Reporting a vulnerability

If you discover a security issue in this repository, including a misleading or unsafe instructional example, please report it privately.

Use one of the following options:

- Open a private security advisory if the repository supports it
- Coordinate with the repository maintainer through a direct private channel
- Submit a non-sensitive issue only when the issue is not a live security risk

## Reporting guidance

Please include:

- A description of the issue
- Where it appears in the project
- Risk or impact severity
- Suggested remediation or documentation fix

## Safe handling expectations

- Do not use this repository for unauthorized testing or exploitation
- Do not target real networks, systems, or cloud resources without permission
- Do not share secret material, credentials, or private data in issues or pull requests

## Response expectations

This project is maintained on a best-effort basis. Security-related reports should be reviewed reasonably quickly, but response times may vary based on repository maintenance activity.

## Educational integrity

The project should not present any exercise as safe or authorized without clearly explaining the boundary conditions. Where lab work is suggested, it should be tied to a controlled environment and explicit permission.
